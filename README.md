# متابع ومزامن منصة جامعة برج العرب التكنولوجية (`BATU LMS Monitor & Sync`)

نظام متابعة وتحميل تلقائي لمنصة جامعة برج العرب التكنولوجية (`https://batechu.com/lms/courses`) مربوط بحسابك الشخصي وبوت تيليجرام (`@ayabusbatubot`).

---

## 1. النظام بيعمل إيه بالظبط؟

1. **تسجيل الدخول التلقائي وحفظ الجلسة:**
   - يقرأ الرقم الأكاديمي وكلمة المرور من ملف [`.env`](file:///c:/Users/ahmed/Documents/antigravity/jolly-hypatia/.env) المحفوظ محلياً على جهازك فقط.
   - يحفظ جلسة الدخول في `cookies.json` عشان يدخل مباشرة في ثواني بدون تكرار تسجيل الدخول كل مرة.

2. **تحميل وترتيب جميع المقررات والمحاضرات على جهازك (`courses/`):**
   - يمر على كل المواد المسجلة لك (7 مواد حالياً) وكل الأسابيع بداخلها.
   - يحمّل كل المحاضرات (`Lectures`) والسكاشن (`Tutorials`) والشيتات (`Sheets`) والتكليفات (`Assignments`) بصيغة `PDF`، وينشئ اختصارات روابط (`URL Shortcuts`) لقوائم يوتيوب والروابط الخارجية.
   - يرتب الفولدرات والملفات بنفس الترقيم والترتيب الموجود على المنصة داخل المسار:
     `c:\Users\ahmed\Documents\antigravity\jolly-hypatia\courses`
   - يحفظ إعلانات وتنبيهات الدكاترة والمعيدين داخل كل مادة في ملف `00 - Announcements (إعلانات المادة).md`.
   - **مزامنة ذكية:** لا يعيد تحميل الملفات الموجودة مسبقاً على جهازك، بل يحمّل الملفات الجديدة فقط فور نزولها.

3. **مراقبة الكويزات والامتحانات والتكليفات وإرسال تنبيهات تيليجرام (`Telegram`):**
   - يفحص الكويزات (`Quizzes`)، والامتحانات الأونلاين (`Online Exams`)، والتكليفات (`Assignments`)، وإعلانات المعيدين والدكاترة (`Announcements`).
   - يقارن البيانات الحالية بآخر حالة محفوظة في `state.json`.
   - يرسل تقريراً منسقاً بالعربي إلى حسابك على تيليجرام عبر البوت `@ayabusbatubot` بالروابط المباشرة للحل أو التسليم.

---

## 2. بيشتغل إمتى وإزاي؟

- **تلقائياً كل يوم الساعة 9:00 صباحاً بتوقيت القاهرة (`Africa/Cairo`):**
  عبر الأتمتة المجدولة **`BATU LMS Daily Quiz Monitor`** (`batu-lms-daily-monitor`).
- **يدوياً في أي وقت تحبه بأمر واحد:**
  ```powershell
  node c:\Users\ahmed\Documents\antigravity\jolly-hypatia\monitor.mjs
  ```
  أو لإرسال تقرير كامل فوري:
  ```powershell
  npm run report
  ```
