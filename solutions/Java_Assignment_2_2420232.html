1. System Name & Identity Project Option #7

Official System Name: SmartCare Clinic Management System (SCCMS) — نظام إدارة العيادات الطبية الذكي

System Identity & Domain: SmartCare CMS is an integrated desktop healthcare management application developed in Java (Java Swing GUI & JDBC) using Apache NetBeans IDE and backed by a relational MySQL Database. It is designed to digitize and streamline daily clinical workflows for outpatient medical clinics, replacing error-prone paper records with a fast, reliable desktop interface.

2. System Aim & Core Services Objectives & Scope

Primary Aim: To enhance patient care quality and clinic operational efficiency by automating patient registration, appointment scheduling, medical visit documentation, prescription generation, and billing within a unified, role-based Java desktop platform.

Core Clinical Services

  • Patient Profile Management: Register new patients, maintain medical history, allergies, blood group, and contact details with instant search by ID or phone.
  • Doctor & Schedule Management: Manage doctor profiles, specializations, working shifts, and consultation fees.
  • Appointment Booking & Queueing: Schedule, reschedule, or cancel appointments while preventing double-booking conflicts.

Administrative & Financial Services

  • Electronic Medical Records (EMR) & Prescriptions: Record diagnosis, vital signs, and prescribed medications per visit.
  • Billing & Invoice Generation: Automatically calculate consultation and service charges, track payment status, and print receipts.
  • Dashboard & Reporting: Generate daily revenue summaries, patient visit counts, and doctor workload statistics.
3. Brief Overview of the System (Functionality, GUI & SDLC) Lecture 5 Integration

System Functionality & User Experience (UX): Built following the Java Swing Containment Hierarchy, the application uses a main top-level container (JFrame) organized into modular sub-containers (JPanel) with intuitive navigation tabs. Users interact with clean data forms (JTextField, JComboBox, JLabel, JButton), tabular views (JTable inside JScrollPane), and interactive feedback dialogs (JOptionPane.showMessageDialog and showConfirmDialog) for validation and confirmation.

  • Workflow Lifecycle: When a patient arrives, the Receptionist logs in, registers or looks up the patient, and books an appointment with an available Doctor. During the consultation, the Doctor opens the patient's record, logs the diagnosis, and issues a digital prescription. Finally, the Receptionist generates the invoice and records the payment.
  • SDLC Methodology (Agile Iterative Model): Following the Software Development Life Cycle (SDLC) best practices, the project is developed iteratively across 6 phases: (1) Requirement Gathering, (2) System & Database Design, (3) GUI & JDBC Development, (4) Unit & Functional Testing, (5) Desktop Deployment, and (6) Continuous Maintenance.

5. Additional Elements (User Roles, Security & System Architecture) Architecture & Security

A. User Roles & Permissions (RBAC)

  • System Administrator: Full access to manage staff accounts, doctor profiles, system settings, database backups, and financial reports.
  • Doctor (Physician): Views assigned daily appointments, accesses patient medical history, records diagnoses, and issues prescriptions.
  • Receptionist: Registers new patients, schedules appointments, manages the waiting queue, and issues patient invoices.

B. Security Measures

  • Password Hashing: User passwords are encrypted using SHA-256 / BCrypt before storage.
  • SQL Injection Prevention: All database queries use JDBC PreparedStatement with parameterized inputs.
  • Input Validation: Front-end Swing form validation using JOptionPane alerts for empty or invalid fields.

C. 3-Tier MVC Desktop Architecture

1. Presentation Layer (Java Swing View): Built with JFrame, JPanel, JTable, and JOptionPane dialogs.
2. Business Logic Layer (Controllers & Models): Java classes (Patient, Doctor, Appointment, Invoice) encapsulating validation and scheduling rules.
3. Data Access Layer (DAO + JDBC): Singleton DatabaseConnection manager communicating with the MySQL database.
